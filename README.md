# NEXUS IMPORTS — versão iPhones / Emagrecedores / Peptídeos

## Alterações desta versão
- Xiaomi removido do site e do pacote.
- Categorias reorganizadas na ordem: **iPhones → Emagrecedores → Peptídeos**.
- Catálogo Apple reduzido para iPhones.
- Imagens dos iPhones exibidos nesta versão apontam para o CDN público do **Atacado Connect**, conforme solicitado.
- WhatsApp continua centralizado no `script.js`.
- Busca com debounce de 150 ms.
- Navegação das tabs por teclado.

## Fonte das imagens dos iPhones
As imagens dos iPhones desta versão são carregadas das páginas/CDN do Atacado Connect. O site lista atualmente modelos Apple como iPhone 13, iPhone 15, iPhone 16 e iPhone 16 Pro.

Site: https://atacadoconnect.com/

## Publicação no GitHub Pages
Mantenha `index.html`, `style.css`, `script.js` e a pasta `assets/` na raiz do repositório.


## Imagens dos iPhones
As imagens desta versão estão armazenadas localmente em `assets/images/iphones/`, para evitar falhas de hotlink/CDN no GitHub Pages. Elas são imagens ilustrativas dos modelos; confirme disponibilidade e cores pelo WhatsApp.
